# K3s

## 개요

이 주제는 로컬 또는 개발 환경에서 사용할 경량 Kubernetes 클러스터 관점을 정리하기 위한 자리입니다.

## 현재 프로젝트 맥락

- 이 저장소는 현재 앱 소스와 로컬 개발 환경 중심으로 유지됩니다.
- 실제 운영 선언은 별도 GitOps 저장소에서 관리합니다.
- 따라서 K3s 문서는 앱 코드보다 배포 대상 환경 관점에서 정리합니다.
